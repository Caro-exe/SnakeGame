# SnakeGame
My first Javascript game, I remade the snake game in google sheets :0 (please be patient with me this is my first game :,) ) 
Okay so essentially I coded this on JavaScript and used a clasp to make sure that it works in google's programming language, App Script. 
Considering that reading keystrokes is limited on google sheets, i made the code have an automation that reads the updates to the sheets! You use WASD to control the snake, but you need to type your move into the cell H1!

# START
Open a new spreadsheet on google sheets and open appscript in extensions
Copy and paste the code from my file
Run the "runthisfunctionfirst" function 
run the "runthisfunctiontostartthegame" function
have fun! Click h16 to start

# CNTRLS
Like I mentioned earlier, this uses WASD
W - Up
A - Left
S - Down
D - Right
Type one of these moves into cell h1 and then press the enter or return key 
click the checkbox to restart the game 
don't hit the walls, or yourself
eat some kiwis (realistically the bird but our snake is vegatarian)
